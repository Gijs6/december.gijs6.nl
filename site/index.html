december

the server behind gijs6.nl and everything below.

why am i here?

december is the little server that runs gijs6.nl and loads of other things.

you probably tried to visit something that lives on here but well... it's been removed :( (or hasn't been made yet).

anyway, below is an overview of what is actually currently being served by december.

sites

  • gijs6.nl: personal site and blog
  • contact.gijs6.nl: contact page
  • timecapsule.gijs6.nl: archive of old versions of gijs6.nl
  • school.gijs6.nl: school summaries
  • craptacular.eu: the best site ever

apps

  • music.gijs6.nl: music collection and wishlist
  • meliag.gijs6.nl: Dutch train departure info
  • outflow.gijs6.nl: weather app
  • cijfers.gijs6.nl: grade calculator
  • huebox.gijs6.nl: color palette app
  • watchtower.gijs6.nl: site change monitor
  • fileflamingo.gijs6.nl: share files with expiring links
  • gemeentle.gijs6.nl: daily Dutch municipality guessing game

infrastructure

  • api.gijs6.nl: REST API server
  • keys.gijs6.nl: public SSH and GPG keys
  • cdn.gijs6.nl: CDN

defunct

  • ckv.gijs6.nl: old CKV site
  • blog.gijs6.nl: old blog, now at gijs6.nl/blog
  • key.gijs6.nl: old SSH key, now at keys.gijs6.nl/ssh
  • archive.gijs6.nl: old archive site, now at timecapsule.gijs6.nl
  • code.gijs6.nl: old code snippets site
